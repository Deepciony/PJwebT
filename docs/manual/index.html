คู่มือฉบับนี้เป็นส่วนหนึ่งของรายวิชา Web Technology and Web Services ภาคเรียนที่ 1 ปีการศึกษา 2569 จัดทำขึ้นเพื่ออธิบายการใช้งานระบบ Arena Hub ระบบจองสนามกีฬาและยืมอุปกรณ์ออนไลน์ที่คณะผู้จัดทำพัฒนาขึ้นตามข้อกำหนดของโครงงาน ระบบประกอบด้วยหน้าเว็บที่ติดต่อกับเซิร์ฟเวอร์ผ่าน REST API เซิร์ฟเวอร์ที่พัฒนาด้วย Node.js และ Express.js ฐานข้อมูล PostgreSQL และเอกสาร API แบบออนไลน์

บทที่ 1ภาพรวมระบบ

Arena Hub คือเว็บแอปพลิเคชันสำหรับสนามกีฬาที่มีกีฬาหลายประเภท (ข้อมูลตัวอย่างมี 19 ประเภท เช่น ฟุตบอล แบดมินตัน บาสเกตบอล เทนนิส ว่ายน้ำ มวยไทย สนุกเกอร์ โบว์ลิ่ง กอล์ฟ และปีนผา) ผู้ใช้ดูช่วงเวลาว่างของทุกสนามได้แบบเรียลไทม์ จองสนามเป็นรายชั่วโมง ยืมอุปกรณ์ไปพร้อมกัน ชำระเงินด้วย PromptPay แล้วใช้ QR เช็คอินที่หน้าสนาม ส่วนเจ้าหน้าที่ใช้ระบบเดียวกันตรวจสลิป เช็คอิน รับคืนอุปกรณ์ จัดการข้อมูล และดูสถิติ

1.1 ผู้ใช้งาน

  • บุคคลทั่วไป ดูตารางว่าง รายละเอียดสนาม อุปกรณ์ และรีวิวได้โดยไม่ต้องเข้าสู่ระบบ
  • สมาชิก (member) จองสนาม ยืมอุปกรณ์ ชำระเงิน ดูประวัติ ยกเลิก รีวิว และแก้ไขข้อมูลส่วนตัว
  • ผู้ดูแลระบบ (admin) ทำได้ทุกอย่างของสมาชิก และจัดการสนาม อุปกรณ์ สมาชิก การชำระเงิน การเช็คอิน และดูสถิติ

1.3 ความสามารถเพิ่มเติม

  • ตารางเวลาว่างของทุกสนามอัปเดตทันทีเมื่อมีคนจอง (Server-Sent Events) ไม่ต้องรีเฟรช
  • กันการจองซ้อนด้วย exclusion constraint ของ PostgreSQL แม้สองคนกดยืนยันพร้อมกัน ระบบให้สำเร็จได้คนเดียว
  • ชำระเงินผ่าน QR PromptPay ตามยอดจริง แนบสลิป และเจ้าหน้าที่อนุมัติหรือปฏิเสธพร้อมเหตุผล
  • ตั๋ว QR สำหรับเช็คอินหน้าสนาม สแกนด้วยกล้องมือถือหรือพิมพ์เลขที่การจอง
  • ยืมอุปกรณ์ตามช่วงเวลา ตรวจสต็อกตามช่วงเวลาที่ทับซ้อน บันทึกการคืน สภาพ และค่าปรับ
  • อีเมลแจ้งเตือนอยู่ในเว็บ: สมาชิกอ่านในกล่องข้อความ ผู้ดูแลระบบดูทุกฉบับ (ยืนยันการจอง ชำระสำเร็จพร้อม QR สลิปไม่ผ่าน ยกเลิก เตือนก่อนเวลา 1 ชั่วโมง) และส่งออกไปอีเมลจริงได้เมื่อตั้งค่า SMTP
  • ผู้ดูแลระบบจัดการหลังบ้านได้ทั้งหมดผ่านเว็บ: ราคาและข้อมูลสนาม อุปกรณ์ คูปอง รีวิว บัญชีสมาชิก ค่าตั้งการจองและ PromptPay ประกาศหน้าเว็บ ข้อมูลติดต่อ สถานะระบบ งานอัตโนมัติ และเอกสาร API ที่ทดลองเรียกได้ทันที
  • รีวิวและให้คะแนนสนามหลังใช้บริการ แดชบอร์ดสถิติรายได้ ช่วงเวลายอดนิยม และสนามยอดนิยม
  • ราคาช่วง peak (เช่น หลัง 17:00 แพงกว่า) ตั้งได้รายสนาม
  • กำหนดได้ว่าจองล่วงหน้าได้กี่วัน (ค่าเริ่มต้น: วันนี้และพรุ่งนี้) และจองประจำทุกสัปดาห์ได้สูงสุด 8 สัปดาห์เมื่อเปิดช่วงจองให้ยาวพอ
  • คูปองส่วนลดแบบเปอร์เซ็นต์หรือจำนวนเงิน กำหนดยอดขั้นต่ำ จำนวนครั้ง และวันหมดอายุได้
  • หน้าตาแบบเมนูเกม: แผงกระจกสีม่วง ขอบลาเวนเดอร์ ปุ่มหลักสีทอง ตัวอักษร Kanit รองรับมือถือ ติดตั้งเป็นแอปบนหน้าจอได้ (PWA) และเป็นภาษาไทยทั้งระบบ

2.2 ขั้นตอนของการจอง

อยู่ในตะกร้า → รอชำระเงิน (15 นาที) → ชำระแล้ว → เช็คอินแล้ว → เสร็จสิ้น

การจองที่ไม่แนบสลิปภายใน 15 นาทีจะเปลี่ยนเป็น หมดเวลาชำระ และคืนช่วงเวลาให้คนอื่นจองได้ สมาชิกหรือผู้ดูแลระบบยกเลิกการจองได้ตามกฎในบทที่ 5

บทที่ 3คู่มือสำหรับสมาชิก

3.1 สมัครสมาชิกและเข้าสู่ระบบ

  1. กด เข้าสู่ระบบ มุมขวาบน แล้วเลือก สมัครสมาชิก
  2. กรอกชื่อ-นามสกุล อีเมล เบอร์โทร (ไม่บังคับ) และรหัสผ่านอย่างน้อย 8 ตัวอักษร แล้วกด สมัครสมาชิก ระบบจะเข้าสู่ระบบให้ทันที
  3. ครั้งต่อไปเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน ระบบจำการเข้าสู่ระบบไว้ 7 วัน

3.2 ดูตารางสนามว่างและเลือกเวลา

หน้าแรกแนะนำระบบ: Arena Hub คืออะไร ทำอะไรได้บ้าง ขั้นตอนการจอง 5 ขั้น กีฬาที่เปิดให้จองพร้อมราคาเริ่มต้น และกติกาการจองที่ใช้อยู่ กด ดูตารางว่างและจองเลย หรือเมนู ตารางว่าง เพื่อไปหน้าจอง

หน้า ตารางว่าง แต่ละแถวคือสนาม แต่ละคอลัมน์คือชั่วโมง เลือกวันที่จากแถบวันที่ (ค่าเริ่มต้นจองได้เฉพาะวันนี้และพรุ่งนี้ ผู้ดูแลระบบปรับได้) และกรองตามกีฬาได้

  • ทุกช่องมีคำบอกสถานะ: ว่าง (สีเขียว) กดเพื่อเพิ่มลงตะกร้า ช่องละ 1 ชั่วโมง เมื่อชี้เมาส์จะขึ้นว่า + จอง
  • ✓ เลือก (สีเหลือง) อยู่ในตะกร้าของคุณ กดอีกครั้งเพื่อเอาออก, ★ ของคุณ (สีม่วง) คือการจองของคุณ, เต็ม (สีเทา) มีคนจองแล้ว
  • ช่องว่างเปล่าคือเลยเวลาแล้วหรือสนามยังไม่เปิด ชั่วโมงปัจจุบันมีป้ายเวลาสีทองที่หัวตาราง
  • เมื่อมีคนยืนยันการจองจากเครื่องอื่น ช่องจะพลิกเปลี่ยนสถานะทันทีโดยไม่ต้องรีเฟรช

กดชื่อสนามเพื่อดูรายละเอียด ราคา เวลาเปิด-ปิด รีวิว และเลือกเวลาของสนามนั้นจากแผงด้านขวา สนามที่มีราคาช่วง peak จะแสดงราคาใต้แต่ละชั่วโมง

จองประจำ: เลือกจำนวนสัปดาห์ในช่อง จองประจำ ก่อนกดชั่วโมง ระบบจะเพิ่มชั่วโมงเดียวกันของทุกสัปดาห์ลงตะกร้า ถ้าสัปดาห์ใดไม่ว่างจะไม่เพิ่มเลยและบอกวันที่ไม่ว่าง ตัวเลือกนี้แสดงเมื่อผู้ดูแลระบบเปิดให้จองล่วงหน้าตั้งแต่ 7 วันขึ้นไป (ค่าเริ่มต้นจองได้แค่ถึงพรุ่งนี้จึงไม่แสดง)

3.3 ยืมอุปกรณ์

  1. เมนู ยืมอุปกรณ์ แสดงอุปกรณ์ทั้งหมด พร้อมค่าเช่า มัดจำ และจำนวนในคลัง
  2. เลือกอุปกรณ์ แล้วเลือกวัน เวลาเริ่ม จำนวนชั่วโมง และจำนวนชิ้น ระบบแสดงจำนวนที่ยังยืมได้ในช่วงเวลานั้น
  3. กด เพิ่มลงตะกร้า ค่าเช่าคิดต่อชิ้นต่อการจอง ส่วนมัดจำจ่ายที่เคาน์เตอร์และได้คืนเมื่อคืนของ
  4. หรือยืมจากหน้าสนามได้เลย: แผง ยืมอุปกรณ์ ใต้แผงเลือกเวลาแสดงเฉพาะอุปกรณ์ของกีฬาสนามนั้น หลังกดเลือกชั่วโมงของสนาม อุปกรณ์จะใช้ช่วงเวลาเดียวกัน (ตั้งแต่ชั่วโมงแรกถึงชั่วโมงสุดท้ายที่เลือก) พร้อมบอกจำนวนที่ยังว่าง

3.4 ตะกร้าและการยืนยันการจอง

ตะกร้าแสดงเลขที่การจอง วันที่สร้าง จำนวนรายการ ยอดรวม และรายการสนามกับอุปกรณ์ทั้งหมด

  • รายการอยู่ทางซ้าย ส่วนสรุปยอด คูปอง และปุ่มยืนยันอยู่ทางขวา กด ลบ ท้ายรายการเพื่อลบทีละรายการ หรือ ลบทั้งตะกร้า ใต้ปุ่มยืนยันเพื่อลบทั้งหมด
  • ถ้ามีคนอื่นยืนยันช่วงเวลาเดียวกันไปก่อน รายการนั้นจะขึ้นป้าย "มีคนจองไปแล้ว" ให้ลบออกก่อนยืนยัน
  • มีคูปอง ให้กรอกรหัสในช่อง รหัสคูปอง แล้วกด ใช้คูปอง ระบบแสดงยอดก่อนส่วนลด ส่วนลด และยอดชำระ ส่วนลดจะถูกล็อกตอนยืนยัน (ทดลอง: WELCOME10 ลด 10% เมื่อยอดถึง 300 บาท)
  • กด ยืนยันการจอง ระบบจะล็อกช่วงเวลาและอุปกรณ์ทั้งหมด หลังยืนยันแล้วแก้ไขหรือลบรายการไม่ได้ ถ้าส่วนลดทำให้ยอดเป็น 0 การจองจะเป็นชำระแล้วทันที

3.5 ชำระเงินด้วย PromptPay และแนบสลิป

  1. หลังยืนยัน ระบบเปิดหน้าการจองพร้อม QR PromptPay ตามยอดที่ต้องชำระและนาฬิกานับถอยหลัง 15 นาที
  2. สแกน QR ด้วยแอปธนาคาร โอนเงิน แล้วกดเลือกไฟล์สลิปในช่อง แนบสลิป
  3. ระหว่างรอเจ้าหน้าที่ตรวจ การจองจะไม่หมดเวลา ถ้าสลิปไม่ผ่าน จะได้อีเมลแจ้งเหตุผลและแนบใหม่ได้อีก 15 นาที

3.6 ตั๋วเช็คอินและกล่องข้อความ

เมื่อสลิปได้รับอนุมัติ หน้าการจองจะแสดง ตั๋วเช็คอิน เป็น QR พร้อมเลขที่การจอง และส่งอีเมลพร้อม QR เดียวกันเข้า กล่องข้อความ บนเว็บ (เมนู ข้อความ มุมขวาบน ตัวเลขสีแดงคือจำนวนที่ยังไม่อ่าน) แสดง QR นี้ที่เคาน์เตอร์เพื่อเช็คอินและรับอุปกรณ์ ก่อนถึงเวลา 1 ชั่วโมงระบบจะส่งอีเมลเตือนอีกครั้ง ถ้าระบบตั้งค่า SMTP ไว้ อีเมลจะถูกส่งเข้าอีเมลจริงของสมาชิกด้วย

3.7 ประวัติการจองและการยกเลิก

เมนู การจองของฉัน แสดงการจองทั้งหมด กรองตามสถานะได้ กดแต่ละรายการเพื่อดูรายละเอียด ประวัติการชำระเงิน และสลิปที่ส่ง

  • ยกเลิกได้ระหว่างรอชำระเงิน หรือหลังชำระแล้วถ้าเหลือเวลาก่อนเริ่มอย่างน้อย 24 ชั่วโมง (เงินที่ชำระแล้ว เจ้าหน้าที่คืนให้นอกระบบ)

3.8 รีวิวสนาม

เมื่อใช้บริการเสร็จ (สถานะเสร็จสิ้น) หน้าการจองจะมีแบบฟอร์มรีวิวสำหรับแต่ละสนามในการจอง ให้คะแนน 1-5 ดาวและเขียนความเห็น รีวิวจะแสดงในหน้าสนามและนำไปคำนวณคะแนนเฉลี่ย

3.9 แก้ไขข้อมูลส่วนตัวและรูปโปรไฟล์

กดรูปโปรไฟล์มุมขวาบน > ข้อมูลส่วนตัว แก้ชื่อและเบอร์โทรแล้วกด บันทึกข้อมูล เปลี่ยนรูปโปรไฟล์ได้จากช่อง เปลี่ยนรูป (JPG, PNG, WEBP ไม่เกิน 5 MB) และเปลี่ยนรหัสผ่านโดยกรอกรหัสผ่านปัจจุบันก่อน

บทที่ 4คู่มือสำหรับผู้ดูแลระบบ

เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบแล้วเลือกเมนู ผู้ดูแลระบบ จะมีแถบเมนูย่อย 11 หน้า ตัวเลขสีแดงข้างเมนูตรวจสลิปคือจำนวนสลิปที่รอตรวจ ส่วนปุ่ม คู่มือ PDF ท้ายแถบเมนูใช้ดาวน์โหลดคู่มือฉบับนี้

4.1 ภาพรวมและสถิติ

เลือกช่วงวันที่ (7, 30, 90 วัน หรือกำหนดเอง) เพื่อดูรายได้ที่อนุมัติแล้ว จำนวนการจอง สลิปรอตรวจ ลูกค้าที่ใช้สนามวันนี้ รายได้รายวัน ช่วงเวลาที่คนจองมากที่สุด รายได้ตามกีฬา สนามยอดนิยม และอุปกรณ์ที่ถูกยืมบ่อย ทุกกราฟกด "ดูเป็นตาราง" เพื่อดูตัวเลขได้

4.2 ตรวจสลิป

หน้า ตรวจสลิป แสดงสลิปที่รอตรวจพร้อมรูปสลิป เลขที่การจอง ชื่อสมาชิก และยอดเงิน กดรูปเพื่อเปิดขนาดเต็ม

  • อนุมัติ: การจองเปลี่ยนเป็นชำระแล้ว และสมาชิกได้อีเมลพร้อม QR เช็คอิน
  • ปฏิเสธ: ใส่เหตุผล สมาชิกได้อีเมลแจ้งและแนบสลิปใหม่ได้อีก 15 นาที

4.3 เช็คอินหน้าสนามและรับคืนอุปกรณ์

  1. หน้า เช็คอิน กด เปิดกล้องสแกน QR แล้วสแกนตั๋วจากมือถือสมาชิก หรือพิมพ์เลขที่การจอง
  2. ระบบแสดงรายการสนามและอุปกรณ์ที่ต้องส่งมอบพร้อมมัดจำที่ต้องเก็บ
  3. เมื่อสมาชิกคืนอุปกรณ์ เปิดรายละเอียดการจอง กรอกสภาพและค่าปรับ (ถ้ามี) แล้วกด รับคืน อุปกรณ์จะว่างให้คนอื่นยืมต่อทันที ถ้ามีค่าปรับ ระบบส่งอีเมลแจ้งสมาชิกทันทีและรวมยอดค่าปรับแสดงไว้ที่หน้ารายละเอียดการจอง (ชำระที่เคาน์เตอร์ ไม่รวมในยอดชำระผ่าน PromptPay)
  4. เมื่อรับคืนอุปกรณ์ครบทุกรายการแล้ว กด เช็คเอาท์ ที่หน้ารายละเอียดการจอง เพื่อปิดการจองเป็นเสร็จสิ้น (สมาชิกรีวิวสนามได้) และส่งอีเมลสรุปพร้อมค่าปรับรวม (ถ้ามี) ปุ่มนี้กดไม่ได้ถ้ายังมีอุปกรณ์ที่ยังไม่คืน

4.4 การจองทั้งหมด

ดูการจองของทุกคน กรองตามสถานะ และค้นหาด้วยเลขที่การจอง ผู้ดูแลระบบยกเลิกการจองที่รอชำระหรือชำระแล้วได้ทุกเวลา

4.5 จัดการข้อมูล: สนาม อุปกรณ์ ประเภทกีฬา และรีวิว

  • แท็บ สนาม และ อุปกรณ์: กด เพิ่มสนาม/เพิ่มอุปกรณ์ หรือ แก้ไข เพื่อเปิดแบบฟอร์ม (ชื่อ กีฬา ราคา เวลาเปิด-ปิด จำนวนในคลัง ค่าเช่า มัดจำ รายละเอียด) ราคาที่แก้มีผลกับรายการที่เพิ่มลงตะกร้าหลังจากนั้น
  • เอาเครื่องหมาย เปิดให้จอง ออกเพื่อปิดสนามหรืออุปกรณ์ชั่วคราว สมาชิกจะไม่เห็นรายการนั้น
  • กด ลบ เพื่อลบสนามหรืออุปกรณ์ที่เพิ่มผิดหรือไม่ใช้แล้ว ถ้าเคยมีการจองแล้ว ระบบจะไม่ลบเพื่อเก็บประวัติไว้ และแนะนำให้ปิดใช้งานแทน
  • กด เปลี่ยนรูป เพื่ออัปโหลดรูปจริงของสนามหรืออุปกรณ์ ถ้าไม่มีรูป ระบบวาดเส้นสนามตามประเภทกีฬาให้
  • ราคาช่วง peak: กรอก ราคาช่วง peak และ peak เริ่มเวลา ในแบบฟอร์มสนาม (เว้นว่างทั้งสองช่อง = ราคาเดียวทั้งวัน)
  • แท็บ ประเภทกีฬา: เพิ่ม แก้ชื่อหรือไอคอน และลบกีฬาที่ยังไม่มีสนามหรืออุปกรณ์
  • แท็บ รีวิว: ดูรีวิวทุกสนาม กรองตามจำนวนดาว และลบรีวิวที่ไม่เหมาะสม คะแนนเฉลี่ยของสนามคำนวณใหม่ทันที

4.6 คูปองส่วนลด

  • เมนู คูปอง แสดงคูปองทั้งหมดเป็นการ์ด: รหัส ชื่อโปร ส่วนลด เงื่อนไข จำนวนที่ใช้ไปเทียบกับที่จำกัด (มีแถบความคืบหน้า) จำนวนสมาชิกที่ใช้ และส่วนลดที่ให้ไปแล้ว ด้านบนสรุปจำนวนคูปองที่เปิดใช้ จำนวนครั้งที่ใช้ และส่วนลดรวม
  • กด สร้างคูปอง ตั้ง ชื่อโปร (เช่น โปรเปิดเทอม) ใส่รหัสเองหรือกด สุ่มรหัส เลือกลดเป็นเปอร์เซ็นต์หรือเป็นบาท และกำหนด จำกัดกี่คน กับ ใช้ได้คนละกี่ครั้ง (ค่าเริ่มต้นคนละ 1 ครั้ง จำนวนสิทธิ์ทั้งหมดจึงเท่ากับจำนวนคน) ยอดขั้นต่ำ และวันหมดอายุ
  • กด ดูการใช้ เพื่อดูทุกการจองที่ใช้คูปองนั้น: วันที่ยืนยัน เลขที่การจอง สมาชิก สถานะ ยอดก่อนลด ส่วนลด และยอดสุทธิ กดเลขที่การจองหรือชื่อสมาชิกเพื่อเปิดรายละเอียด
  • แก้ไข เปลี่ยนส่วนลดหรือเงื่อนไข หรือปิดคูปอง (การจองที่ยืนยันแล้วยังได้ส่วนลดเดิม) ลบ ได้เฉพาะคูปองที่ยังไม่มีใครใช้
  • สมาชิกที่ใช้ครบสิทธิ์ของตัวเองแล้วจะได้ข้อความ "คูปองนี้ใช้ได้คนละ … ครั้ง และคุณใช้ครบแล้ว" ตอนกดใช้คูปองในตะกร้า

4.7 จัดการสมาชิก

  • ค้นหาด้วยชื่อหรืออีเมล และกรองตามสิทธิ์
  • ระงับ/เปิดใช้งาน: สมาชิกที่ถูกระงับเข้าสู่ระบบไม่ได้ และ token เดิมใช้ไม่ได้ทันที
  • ตั้งเป็นแอดมิน/ปลดจากแอดมิน และ เพิ่มผู้ใช้ ใหม่ (เช่น บัญชีพนักงาน) ผู้ดูแลระบบเปลี่ยนสถานะหรือสิทธิ์ของตัวเองไม่ได้
  • กดชื่อสมาชิกเพื่อดูจำนวนการจอง ยอดใช้จ่าย และประวัติการจองทั้งหมดของคนนั้น
  • ในหน้าสมาชิก 1 คน กด แก้ไขข้อมูล เพื่อแก้ชื่อ อีเมล หรือเบอร์โทร และ ตั้งรหัสผ่านใหม่ เมื่อสมาชิกลืมรหัสผ่าน แล้วแจ้งรหัสให้สมาชิกไปเปลี่ยนเองที่หน้าข้อมูลส่วนตัว

4.8 อีเมลของระบบ

เมนู อีเมล แสดงอีเมลทุกฉบับที่ระบบส่งให้สมาชิก ค้นหาจากผู้รับ ชื่อ หรือหัวเรื่อง กรองตามประเภทและสถานะการส่ง กดรายการเพื่ออ่านเนื้อหาเหมือนที่สมาชิกเห็น สถานะ ในเว็บ คืออยู่ในกล่องข้อความของสมาชิก ถ้าเซิร์ฟเวอร์ตั้งค่า SMTP ไว้ จะเห็นสถานะ ส่งออกแล้ว หรือ ส่งออกไม่สำเร็จ และกด ส่งออกอีกครั้ง ได้

4.9 ระบบหลังบ้านและค่าตั้งระบบ

  • แก้ PromptPay ที่รับเงิน, เวลาชำระเงิน, ยกเลิกได้ก่อนเริ่ม, เช็คอินล่วงหน้าได้ และ จองล่วงหน้าได้ แล้วกด บันทึกค่าตั้งระบบ มีผลกับรายการถัดไปทันทีโดยไม่ต้องรีสตาร์ทเซิร์ฟเวอร์
  • ข้อมูลสนามและประกาศ: ข้อความ ประกาศหน้าเว็บ แสดงเป็นแถบสีเหลืองบนทุกหน้า (เว้นว่างเพื่อซ่อน) ส่วน เบอร์ติดต่อ, LINE ID และ ที่อยู่ แสดงท้ายเว็บและท้ายอีเมลทุกฉบับ
  • สถานะระบบ แสดงการเชื่อมต่อฐานข้อมูล เวอร์ชัน PostgreSQL การส่งอีเมลออก งานอัตโนมัติครั้งล่าสุด จำนวนข้อมูล และ migration ที่รันแล้ว
  • กด รันตอนนี้เลย เพื่อสั่งงานอัตโนมัติทันที (ปกติรันเองทุก 1 นาที)

4.10 API ในหน้าผู้ดูแลระบบ

เมนู API เปิดเอกสาร API ฉบับเต็มไว้ในหน้าผู้ดูแลระบบ กด Test Request เพื่อเรียก endpoint จริงด้วยสิทธิ์ของบัญชีผู้ดูแลระบบที่เข้าสู่ระบบอยู่ได้ทันที ไม่ต้องคัดลอก token

4.11 ข้อมูลระบบ

เมนู ข้อมูลระบบ (เปิดได้ทุกคนที่ /about หรือจากลิงก์ท้ายเว็บ) สรุปด้านเทคนิคของ Arena Hub สำหรับการนำเสนอ: ภาพรวม 3 ชั้น (หน้าเว็บ, API, ฐานข้อมูล), เทคโนโลยีที่ใช้แต่ละส่วนและหน้าที่, แผนภาพความสัมพันธ์ของตาราง (ER diagram) พร้อมคอลัมน์ของทุกตาราง, สิ่งที่ฐานข้อมูลบังคับเอง (ENUM, VIEW, exclusion constraint, CHECK, foreign key), สถานะของการจอง, กลไกสำคัญ เช่น กันจองซ้อนและสต็อกอุปกรณ์, โครงสร้างไฟล์ และจำนวน endpoint ที่นับจากเอกสาร API จริง

6.1 ตัวอย่างการเรียกใช้

# 1) เข้าสู่ระบบ ได้ token กลับมา
curl -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"member@sporthub.local","password":"member1234"}'

# 2) ใช้ token เรียก endpoint ที่ต้องเข้าสู่ระบบ
curl -X POST http://localhost:3000/api/v1/cart/slots \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"courtId":3,"startAt":"2026-10-08T18:00:00+07:00"}'

ทุก error ใช้รูปแบบเดียวกัน เช่น {"error":{"code":"SLOT_TAKEN","message":"ช่วงเวลานี้มีผู้จองแล้ว"}} โดย status 400 = ข้อมูลไม่ถูกต้อง, 401 = ยังไม่เข้าสู่ระบบ, 403 = ไม่มีสิทธิ์หรือบัญชีถูกระงับ, 404 = ไม่พบข้อมูล, 409 = ขัดแย้งกับสถานะปัจจุบัน

บทที่ 7การติดตั้งและทดสอบระบบ

7.1 สิ่งที่ต้องมี

Node.js 24, pnpm และ Docker Desktop (สำหรับ PostgreSQL)

7.2 ติดตั้งและรัน

docker compose up -d     # PostgreSQL 18 (พอร์ตถูกใช้: ตั้ง DB_PORT ใน .env)
pnpm install
pnpm db:migrate          # สร้างตาราง
pnpm db:seed             # ข้อมูลตัวอย่าง (หรือ pnpm db:reset เพื่อล้างและสร้างใหม่)
pnpm dev                 # API :3000 และเว็บ :5173

ต้องการฐานข้อมูลชุดเดียวกับอีกเครื่อง: เครื่องต้นทางรัน pnpm db:export แล้ว commit โฟลเดอร์ apps/api/db/snapshot/ เครื่องปลายทางรัน pnpm db:import แทน db:migrate และ db:seed จะได้ทุกตาราง ทุกการจอง และไฟล์สลิปเหมือนกัน

7.3 ทดสอบ

pnpm test                # ชุดทดสอบ API 113 กรณี กับฐานข้อมูล sporthub_test

ชุดทดสอบครอบคลุมการสมัครและสิทธิ์ การจัดการสนามและอุปกรณ์ ตะกร้า การยืนยันพร้อมกันสองคน (จองซ้อนและยืมเกินสต็อก) การชำระเงิน อีเมล การเช็คอิน การคืนอุปกรณ์ รีวิว งานอัตโนมัติ และสถิติ

7.4 Production

docker build -t sporthub .
docker run -p 3000:3000 -e DATABASE_URL=... -e JWT_SECRET=... sporthub

image เดียวสร้างหน้าเว็บและรัน API ซึ่งเสิร์ฟหน้าเว็บบนโดเมนเดียวกัน และ migrate ฐานข้อมูลให้ตอนเริ่มทำงาน รายละเอียดค่าที่ตั้งได้อยู่ในไฟล์ .env.example
